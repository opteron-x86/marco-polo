Marco Polo — A Skyrim Economy Mod, 0.1.5.

Regional merchanting now has a narrower buy/sell spread and stronger export/import differences. Speech, perks and merchant modifiers remain effective through the game's live barter factors. Selected long routes for drinks, weapons, silver and household goods can return twice the purchase outlay in automated shipment tests, including travel time and finite merchant gold. Buying raises local prices and deliveries reduce the margin. Actual stock, player bonuses and arrival conditions determine in-game returns.

Ale, mead, wine, brandy and Hearthfire/Dragonborn alcohol now belong to Drink. Optional OCF and VendorItemDrinkAlcohol keywords cover mod-added alcohol. Quest-instance protections remain. Market bulletins describe high and low prices without claiming that every expensive import is a stock shortage. Contracts remain exclusive to the optional Missives addon.

One DLL targets Skyrim SE 1.5.97 and AE 1.6.x / 1.7.x through alandtse CommonLibSSE-NG. The 1.6.1170-only loader check and whitelist are removed, the legacy Query export is provided, and inventory resets select the SE/AE Address Library ID. Use matching SKSE and Address Library for the installed executable and a compatible SkyUI barter menu. The core needs no ESP or Papyrus scripts; the optional Missives ESP is unchanged.

Existing economies retain their stocks, merchants, contracts, shipments, time and prices on load. The spread changes immediately; saved prices converge toward the new regional pattern as game days pass. No new game is needed. Schema 2 is unchanged, with schema-1 migration retained. Install the DLL and both updated economy/classification files together after exiting Skyrim.

Automated checks exercise route profitability, declining margins, local-resale protection, merchant cash, legacy configuration, save restoration and runtime metadata/relocations. The 0.1.5 gameplay changes need in-game confirmation. Earlier 1.6.1170 purchase tests passed; the unrelated exit-to-menu failure and original affected Markarth saves remain unresolved.
