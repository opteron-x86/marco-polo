Marco Polo — A Skyrim Economy Mod, 0.1.0.

Initial experimental build for game testing: ten regional markets, 24 commodities, seasonal production, finite stock, delayed shipments, supply-sensitive barter and save-specific persistence. Optional Missives bulletins and fixed-term supply contracts; optional SKSE Menu Framework ledger.

Requires Skyrim SE Steam 1.6.1170, matching SKSE/Address Library and a compatible SkyUI barter menu. Install the main ZIP. The Missives ZIP is optional and requires Missives; symbols and source are for development.

Native simulation tests and the Windows build are automated. In-game validation is pending, especially menu quotes versus gold, merchant resets and compatibility with other mods. Use a separate test save and the included TESTING.md checklist. The core needs no ESP or Papyrus; the Missives addon supplies an ESL-flagged ESP without scripts or dialogue.
